### 🔧 Требования

- Docker + Docker Compose
- Java 17
- Postman или curl для тестов (необязательно)

---

### 🐳 Запуск

1. Перейдите по пути куда устоновили сервис ```cd C:\ваш_путь```
2. после выполните команду:
```

docker-compose up -d

```

### Инструкция по использыванию

Отправка регестрации http://localhost:8080/auth/request-code желательно делать через POstMan</br>
